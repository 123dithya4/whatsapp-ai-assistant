# WhatsApp AI Assistant 🤖

A simple AI chatbot for WhatsApp built using Python, Flask, Groq, and Twilio.

## ✨ Features

- AI-powered WhatsApp chatbot
- Twilio WhatsApp integration
- Groq AI integration
- Calculator tool
- Weather tool
- Conversation memory

## 🛠️ Technologies

- Python
- Flask
- Groq
- Twilio
